## 💡 사용 방법

**LLM에게**: "wiki에서 [주제] 찾아줘" 라고 하면 관련 파일 + 출처 경로를 보여줍니다.

**예시**:
- "wiki에서 구상금 변제 기한 찾아줘" → `03_조항_표준.md` + `05_법률_개념.md` 참조
- "wiki에서 별지에 ⑦항 왜 추가했는지" → `04_법적_결정.md` 참조
- "wiki에서 B2B 손해배상금 산식" → `08_B2B_약관.md` + `04_법적_결정.md` 참조

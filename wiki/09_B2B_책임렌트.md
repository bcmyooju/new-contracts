## 🎯 책임렌트의 본질

- **회사**: 한국모터사이클리스(한모사) — 계약 주체·세금계산서 발행
- **수납대행**: 포어스바이크 — 모든 입금(렌트료·보증금) 받음
- **보험 가입 주체**: 회사 (단, **책임보험만**)
- **차량 소유권**: 회사 (계약 종료 시 회사 회수, 인수 옵션 없음 또는 별도 협의)
- **B2B 특성 그대로**: 계약자=사업장(배달대행사), 사용자=라이더, 연대보증인=법인대표(법인 한정)

### 종합렌트(포어스) vs 책임렌트(한모사) 핵심 차이

| 구분 | 종합렌트 (포어스) | 책임렌트 (한모사) |
|---|---|---|
| 회사 | 포어스바이크 | 한국모터사이클리스 |
| 보험 | 종합보험 (대인Ⅰ+Ⅱ·대물·자손·자차) | **책임보험만** (대인Ⅰ·대물) |
| 부족 보장 | 회사 가입 보험으로 대부분 처리 | **자차·자손 등은 보장 없음 → 손해 시 계약자 부담 명시 필요** |
| 단가표 | 종합보험 단가표 | **책임보험 단가표** (사이즈별·연령별) |
| 격락손해금 | 만기 시 지급 (할부 없을 시) | 동일 |
| 인수형 옵션 | 있음 (완납 시 명의이전) | 옵션 있음 단, 종합렌트 대비 활성도 낮음 |

## 📜 v4 조항 구조

종합렌트 v6_단가표반영_v2.5 와 동일한 29개 조항 + 별지_단가표 (책임보험 사이즈별 단가) 보유.

→ 차이는 본문 안의 **회사명·상품명·보험 표현·단가표 단가**만 다름.

### 책임렌트 전용 표현 (종합렌트와 다른 부분)

- **제2조 ⑪ 책임보험 정의 강조** (자손·자차 보장 없음 명시)
- **제10조 (보험계약)**: 회사가 **책임보험에 한해** 가입한다 명시. "종합보험 보장은 적용되지 아니한다" 명시
- **제13조 (보험 면책사고 및 구상금)**: 책임보험 미보장 사고 (자차·자손 등) 손해는 계약자 부담 명시
- **제15조 등 사고 처리**: "책임보험 보장 범위 외 손해는 계약자가 직접 부담" 표현

## 🔄 v3 → v4 작업 핵심 (이번 세션 직전)

- **v3 → v4 사용자 지적사항**:
  1. "**본 이륜차 종합렌트 계약서**" 잔재 (B2/B51 동의문) → "**본 이륜차 책임렌트 계약서**"로 수정
  2. B3 회사명 잔재 → 한국모터사이클리스로 통일
  3. C53 공급자 서명 → 한모사
  4. 본문 곳곳 "종합렌트" 잔재 → "책임렌트"
  5. **보증금 계좌**: 사용자가 한모사 계좌로 잘못 적었다가 → "수납은 포어스(수납대행)"로 정정 (B2C와 동일 원칙)

→ 이때 사용자 피드백: *"보증금도 포어스 바이크가 관리하는데ㅠㅠ ... 입금은 무조건 다 포어스바이크 계좌로 하는거야 계산서는 한모사가 발행하고"*

→ **법칙 확정**: 한모사 계약(책임렌트·할부판매)의 모든 입금은 **포어스 계좌**로. 한모사는 세금계산서만 발행.

## 💸 책임보험 단가표

- 사용자가 제공한 사이즈별 단가표를 별지_단가표 시트에 반영
- 처리지체 위약금 산정 시 "(일사용료 × 1.2) × 지체일수" 산식이 종합렌트와 같이 작동하나, 인수형 완납 후 손해배상금에는 사이즈별 책임보험 단가가 들어감

## 🧪 작업 시 유의 (v2~v4 세션 교훈)

- **종합렌트 잔재 검수 필수**: 종합렌트 베이스로 만들었기 때문에 본문·시트명·동의문·공급자 서명에 "종합렌트"·"포어스" 잔재가 남기 쉬움. 단어뿐 아니라 "종합렌트와 관련된 안내문" 통째로 점검.
- **보증금/렌트료 계좌**: 한모사 계약이라도 모두 포어스 계좌. 잘못 적으면 운영 사고.
- **B2B 매크로 셀 매핑**: B2B는 1면에 연대보증인 박스 추가로 B2C 대비 셀이 3행 시프트됨.

## 💡 메시지 사용 팁

1. **작업 폴더 경로**: 컴퓨터마다 사용자명이 다르니 `<내사용자명>` 부분만 본인 거로 바꿔서 사용
2. **GitHub 클론 후 사용**: 새 계정/새 컴퓨터에선 먼저 GitHub repo를 클론한 후 그 폴더 위치를 알려주는 게 안전
3. **wiki만 보고도 90% 컨텍스트 복원 가능**: 나머지 10%는 작업하면서 자연스럽게 합의

## 🔁 매 세션 종료 시 권장

- 큰 결정·새 작업 → 해당 wiki 파일에 추가
- `07_펜딩_TODO.md` 갱신
- 변경된 wiki → Git 푸시

이러면 모든 컴퓨터·계정에서 동일한 컨텍스트로 작업 가능.

## 🌍 다른 계정으로 옮길 때

### 같은 컴퓨터에서 계정만 바뀜

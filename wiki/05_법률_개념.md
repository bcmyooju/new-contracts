# 05. 법률 개념 빠른 참고

## ⚖ 지급명령 (民事訴訟法 462조 이하)

**개요**: 금전 청구 단순 사안에 대해 변론 없이 법원이 명령 내리는 약식 절차.

### 흐름
1. **신청자(회사)** → 전자소송 포털에서 지급명령 신청
2. 법원이 상대방(채무자)에게 송달
3. **2주 안에 이의신청 안 함** → 지급명령 확정 → 확정판결과 동일 효력 → 강제집행 가능
4. **이의신청 함** → 자동으로 정식 민사소송으로 이행 → 인지보정명령 (정식 소송 인지대 9/10 추가 납부 필요) → 변론·증거제출·판결

### 송달 안 될 때
- 지급명령은 공시송달 불가 (원칙) → 송달 안 되면 법원이 소송절차로 이행

### 강제집행 (확정 후)
- 송달증명원 + 확정증명원 발급 (전자소송 포털)
- **채권압류 및 추심명령** (가장 흔함, 통장 압류)
- 채무자 자산 모르면 재산명시신청·재산조회신청

### 인지대
- 지급명령 = 정식 소송 인지대의 1/10
- 이의신청 시 나머지 9/10 보충 납부 필요

## ⚖ 소액소송 (3,000만원 이하)

**한모사 입장 적용**: 미수금 회수용. 라이더 미수금은 대부분 3천만원 이하.

### 누가 원고?
- **계약 당사자 = 한모사** (한모사가 원고)
- 포어스는 수납대행사라 원고 자격 X (채권 양도 받으면 가능)
- 법인 본인소송은 **임직원만 가능**, 외부 위탁은 변호사만

### 전자소송 시스템
- 양식대로 빈칸 채우면 가능 → 변호사 없이 충분히 진행

## 📑 구상금 vs 배상금 — 법적 차이

| 구분 | 구상금 | 배상금 (손해배상금) |
|---|---|---|
| 본질 | 회사가 **이미 지출한 돈을 회수**하는 권리 (구상권) | 사고로 입힌 **직접 손해 보상** |
| 흐름 | 보험사 → 회사 → 계약자 (또는 회사 → 제3자 배상 후 → 계약자에게 청구) | 가해자가 피해자에게 직접 / 회사가 가해자에게 청구 |
| 시점 | 회사가 이미 돈 지급한 상태 (절차 있음) | 사고 직후 발생 (즉시) |

**실무**: 무면허·음주 사고도 결국 보험사 면책 → 구상금으로 회수되는 케이스가 대부분.
**약관 통일**: 7일 이내 변제 기한으로 통일 (둘 다)

## 💸 차임 상당 손해배상 (B2B 손해배상금 산식 근거)

**개념**: 계약 종료 후에도 계약자가 차량을 반환하지 않고 점유하면, 회사는 그 차량을 다시 임대하지 못해 손해를 입는다. 이때 회사가 청구할 수 있는 손해 = "차임(렌트료) 상당액".

- **민법상 표준** — 임대차 종료 후 목적물 미반환 시 "차임 상당의 부당이득 또는 손해배상" 인정이 판례 확립.
- **B2B 제7조 손해배상금 ①호 "사용수익 상실액"이 이것**: `(일사용료 × 1.2) × 지체일수`
  - 일사용료 100% = 차임 상당 손해
  - 추가 20% = 처리 지체에 대한 위약 가산 (위약금 산식의 20%와 비율 통일)
- 20% 정도 가산은 약관규제법상 "과도한 손해배상 예정"으로 보기 어려움 → 안전.

## ⚖ "인도(引渡)" — 법률 용어
- **뜻**: 물건의 점유를 넘기는 것. "차량 인도를 청구할 수 있다" = "차량을 회사에 돌려달라고 청구".
- **흐름**: 해지 사유 발생 → 회사가 "인도 청구"(정식 반환 요구) → 안 주면 인도 소송 → 판결 → 강제집행. 약관의 "임의 회수"(실력 행사)보다 한 단계 앞의 권리.
- B2B(사업자 대상)는 법률 용어 그대로 두어도 무방. 친숙하게 하려면 "차량 반환을 청구"로 대체 가능.

## 🛡 보험 가입자 vs 차량 소유자 — 피보험이익 문제

**시나리오**: A 명의 차량에 B가 본인 보험 가입 → 사고

### 법적 위험
- 보험사가 "B는 피보험이익 없다" (상법 668조)로 면책 가능
- 결과: 피해자가 **소유자(A)에게 직접 청구** → A(회사)가 손해

### 약관 대응 (할부판매 핵심)
> "계약자는 **본인 명의로** 본 계약 차량의 자동차보험에 가입할 의무가 있으며, ... 부적합 보험 가입·**본인 명의 아닌 보험 가입** 등으로 보험처리가 불가하거나 보험금으로 충당되지 않는 손해는 전적으로 계약자가 부담한다."

### 실무 운영 권장
1. 본인 명의 보험가입증명서 필수 제출
2. 유상운송 특약 가입 여부 확인 (배달 라이더 핵심)

## 🏢 개인사업자 vs 법인 — 연대보증 필요성

| 구분 | 개인사업자 | 법인 |
|---|---|---|
| 법인격 | 없음 (사업체 = 자연인 본인) | 있음 (별개 인격) |
| 폐업·청산 시 채무 | 개인 본인에게 그대로 귀속 | 법인 재산 한도 (유한책임), 대표 개인 책임 X (원칙) |
| 연대보증 필요? | **불요** (본인이 곧 채무자, "본인이 본인을 보증"은 무의미 — 민법 428조) | **필요** (대표 개인 연대보증을 받아야 추가 채권 확보) |

→ **B2B 약관**: 연대보증인은 "법인 계약자에 한함". 개인사업자는 별도 연대보증인 두지 않음.

## 💰 이자율 정리

| 종류 | 이자율 | 적용 |
|---|---|---|
| 민법 법정이율 | 연 5% | 약정 없는 일반 채무 |
| 상법 법정이율 | 연 6% | 상행위 채무 |
| 소촉법 (판결 후) | 연 12% (2019.6~) | 소송 판결 받은 금전채무 |
| **이자제한법 상한** | 연 20% (2021.7~) | 약정 가능 최고 한도 |

**현재 약관**: 연 15% (한도 내 안전)

## 📜 약관규제법 핵심

### 회사가 약관에 넣을 때 주의할 점
1. **명시·설명 의무** — 중요 조항은 별도 설명 (별지 분리 + 별도 서명이 강력). 가독성도 명시·설명 의무의 일부 → 약관 글씨가 너무 작으면 "안 읽었다" 주장 빌미.
2. **현저히 불리한 조항 무효** — 너무 짧은 기한 (3일 이내 변제 등), 과도한 위약금 무효 가능
3. **약관 변경 시 통지** — 14일 전 서면 통지 필수 (약관 변경 조항으로 명시)

### B2C 적용 (소비자보호법 추가)
- 소비자에게 일방적으로 불리한 조항 → 무효 가능성 큼
- 따라서 별지 분리 + 서명 받는 게 회사 보호에 강력
- **B2B는 사업자 간 계약**이라 소비자보호법 적용 X → 약관규제법만 적용. 다소 강한 조항도 B2C보다 유효성 인정 폭이 넓음.

## ⚖ 약관규제법상 위약금·기한 기준

- **약정 가능 위약금**: 잔여기간 렌트료의 20% + 보증금 회사 귀속 (산식 명시 권장)
- **변제 기한**: 7일 안전, 5일 가능, **3일은 다툴 여지 있음**
- **법원 감액 가능** (민법 398조 ②): 과도한 손해배상 예정 시 법원이 감액 가능
- **손해배상금**: "실손해 기반"이면 한도 없음 (실비 청구). 정액 위약 성격이면 과도하면 감액 위험 → B2B 손해배상금은 "사용수익 상실(실손해성) + 실비"로 구성해 안전.

## 🎯 B2C vs B2B 핵심 차이

| 구분 | B2C | B2B |
|---|---|---|
| 계약자 | 라이더 본인 (개인) | **사업장 (배달대행사)** |
| 사용자(라이더) 개념 | 없음 (계약자=운전자) | **있음** — 계약자가 지정·관리, 실제 운행자 |
| 연대보증인 | ❌ 없음 (제거함) | ✓ **법인 계약자만** (개인사업자는 본인이 곧 채무자라 불요) |
| 계열사 동시 해지·미납 교차 | ❌ 1인 1대라 의미 X | ✓ 한모사↔포어스 양방향 |
| 자동이체 입력란 (1면) | ✓ (선택, 향후 대비) | ✓ |
| 사용자 자격 관리·감독 조항 | 없음 | ✓ **제8조 신설** (B2B 핵심 면책 조항) |

## 👤 B2B "사용자(라이더)" 개념 — 중요

B2B에서는 **계약자 ≠ 운전자**:
- **계약자** = 본 계약 1면에 기재된 사업장 (배달대행사). 모든 채무 부담.
- **사용자** = 계약자가 지정·관리하는 자로서 실제로 이륜차를 운행하는 자 (라이더).
- 회사는 사용자의 신원·자격·연령을 사전 확인할 의무 없음.
- 사용자가 일으킨 사고·손해·구상금은 **관리·감독을 해태한 계약자가 전적으로 책임**.

→ 약관 곳곳에서 "계약자가 사용자에게 운행하게 한 경우에도 운행자성·책임은 계약자에게 있다" 표현 필수.
